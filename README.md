# MSCS_634_Lab 1: Data Visualization, Data Preprocessing, and Statistical Analysis using Python in Jupyter Notebook
The dataset used for this lab was the Daily Weather Dataset downloaded from Kaggle.com. Weather affects our day to day lives through affecting how we plan our activities and travel, how much crops grow, and even what time of day we plan our schedules around. Using this dataset allows us to evaluate and compare various weather related measurements like rainfall, temperature, humidity, air pressure, wind speed, etc. The dataset has many attributes and many entries, making it very beneficial for visualizing data, pre-processing data, and statistical analysis. Additionally, this type of dataset will allow you to study and learn about weather trends and potentially assist in predicting weather or supporting decision-making processes in the future.

During this lab, there were a variety of ways to clean and preprocess the data. First, we evaluated the amount of missing data by summing the number of NULLs in each column. We then applied mean imputation to replace all of the missing data in the numerical columns with the average value in those columns. Doing so allowed us to create a complete dataset with no missing values to avoid any errors when analyzing the data. Next, we identified and dealt with outliers in the temperature data by applying the IQR method. Then, we utilized sampling to perform a data reduction on the dataset to decrease its size and to remove unimportant columns to eliminate the unnecessary dimensionality. Lastly, we normalized the numerical values of the dataset using scaling and grouped the temperature into categories such as Cold, Mild, and Hot utilizing discretization.

We discovered many useful patterns and insights in both the data visualizations and statistical analysis. From the scatter plot, I noticed a strong connection between humidity and temperature. In many cases, there were different humidity patterns associated with higher temperature values. Therefore, it appears that weather variables are related to one another. The histogram indicated that the majority of the temperature values were in a normal range, however, there were a few extreme values. It appeared to indicate that the dataset contained typical weather patterns, but there were a few unusual days included. The box plot assisted in identifying outliers in the temperature data. There were a few values that were extremely different from the rest of the temperature values, possibly representing extreme weather days or incorrect values.

In addition to providing a good understanding of the types of values present in the dataset, the statistical measures also assisted in summarizing the overall characteristics of the dataset. Important statistical measures including mean, median, mode, variance, and standard deviation were calculated. Calculating these statistical measures provides an excellent way to understand how spread out the values are in the dataset and provide a better understanding of the data distribution. The correlation matrix further assisted in demonstrating which weather features were connected to one another. A stronger correlation exists in some columns compared to others, indicating that the variables are changing in conjunction with each other. These findings can assist in determining which features would be useful for future weather predictions and analysis.

Some of the challenges encountered during the lab were that missing values in the dataset were not always apparent in the dataset previews generated using random sampling. At times, the sample(5) output did not contain any missing values due to the fact that missing data can occur rarely. To resolve this issue, I presented the rows containing missing values before and after cleaning so that it was obvious how the data changed. Another decision made was to utilize temperature variables in the visualizations and outlier detection since the rain data had many zero values and did not typically display meaningful patterns. With these challenges and decisions, the data was successfully cleaned and prepared for more in depth analysis.
